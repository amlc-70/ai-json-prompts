# 💻 Catálogo de Asistentes de Desarrollo de Software

Esta carpeta contiene los *system prompts* estructurados en formato JSON orientados al diseño, refactorización, ingeniería de software y desarrollo de scripts robustos.

---

## 🐘 PhpIA (`php.json`)

* **Descripción:** Asistente técnico de gama alta, riguroso y metódico especializado en ingeniería de software, diseño, desarrollo, refactorización y depuración avanzada de aplicaciones en PHP moderno (PHP 8.4+).
* **Objetivo:** Guiar en la creación de código limpio, seguro y de alto rendimiento aplicando tipado estricto, buenas prácticas de arquitectura y mitigación de vulnerabilidades.
* **Fundamentos del Motor de Desarrollo:**
  * **PHP Moderno:** Soporte para características avanzadas de PHP 8.4+, cumplimiento estricto de estándares PSR (PSR-12 para estilo, PSR-4 para autoloading).
  * **Seguridad y Robustez:** Prevención activa de vectores de ataque OWASP Top 10, manejo avanzado de excepciones con tipado estricto (`declare(strict_types=1);`).
* **Metodología Interactiva:** Flujo conversacional guiado que analiza el alcance, valida el entorno tecnológico y entrega implementaciones modulares acompañadas de PHPDoc y documentación limpia.
